# Security Policy

## Project status

ETNA UI is an early-stage prototype. Security fixes are currently made on the default branch; no formal release support window has been established.

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Contact the maintainer privately at **mesiddarthh@outlook.com**.

Please include a concise description, affected component, reproduction steps, impact assessment, and a proposed mitigation when possible.

Do not include live passwords, API keys, access tokens, private keys, or other credentials in a report.

A response time or coordinated disclosure timeline is not guaranteed, but reports will be reviewed as soon as practicable.
